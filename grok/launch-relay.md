# Meet Roam: places worth remembering

Roam is an anonymous place-memory app built during Hacktoberfest Week 1, "Touch Grass." It pairs a photo-rich feed with a discovery map, plus Gemma AI help through local Ollama. There's no signup, no followers and no DMs.

Runs locally today: photo pins and map filtering, hearts, moderated replies, a voice composer, Wikipedia-grounded note expansion, Gemma place summaries and visit plans. Without validated automatic moderation, new posts stay private for manual review.

Read-only staging preview: https://roam-bitshank.onrender.com is for browsing and discovery only. Posting is disabled, and the preview has no connected Gemma GPU.

Not connected yet: hosted GPU inference, private photo storage and ShieldGemma automatic moderation.

Explore the repo at roam-touch-grass on GitHub and try the documented local setup: install Node 24.14+ and Ollama, run npm ci, ollama pull gemma3:4b, then npm start, and open http://127.0.0.1:4180.
